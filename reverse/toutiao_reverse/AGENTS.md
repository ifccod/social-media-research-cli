# 头条平台记忆

## 适用范围

本文件约束今日头条公开 HTTP 客户端；测试和页面/JSON 夹具位于 `test/toutiao/`。

## 当前研究记忆

- 文章、视频、评论、搜索、热榜和用户资料来自不同移动/公开接口；引用解析先确定作品类型和稳定 ID。
- 视频播放信息、vod 数据和页面 metadata 是不同层次，归一化时保留来源字段和媒体类型。

## 已知坑与解决方式

- 数字 ID 保持字符串精度，短链接只允许官方主机和有限跳转；外部最终地址不能进入解析器。
- HTML 访问页、空 JSON 和 API 业务错误不可当作成功空列表；分页 cursor 重复时停止。

## 验证与证据

- 固定样本位于 `test/toutiao/fixtures/`，覆盖文章、视频、评论、搜索和用户路径。
- 修改后运行 `make test PYTHON=.venv/bin/python`。
