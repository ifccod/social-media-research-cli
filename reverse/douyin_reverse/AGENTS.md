# Douyin 平台记忆

## 适用范围

本文件约束 Douyin Web/公开分享客户端；测试和 HTML/JSON 夹具位于 `test/douyin/`。

## 当前研究记忆

- 分享短链、视频页、用户页、评论和搜索是不同的公开入口，先解析并校验归属，再请求详情。
- Web 评论和搜索的登录态请求通过被动浏览器会话桥；普通分享页和移动公开接口保持纯 Python HTTP。
- aweme、sec_uid、游标和重定向地址都要做严格的响应身份校验。

## 已知坑与解决方式

- 短链只允许有限跳转并逐跳校验官方主机、端口和路径，不能直接信任最终 URL。
- 页面挑战、空 router 数据和访问页不是成功响应；分类后立即结束当前入口，不做无界重试。
- 评论与回复游标必须前进，批量操作逐项隔离错误并保持输入顺序。

## 验证与证据

- 夹具放在 `test/douyin/fixtures/`，浏览器合同测试使用 mock，不启动真实页面。
- 修改请求、解析或签名后运行 `make test PYTHON=.venv/bin/python`。
