# Google AI Studio 视频理解与广告再创作流水线

## 状态

- 阶段：产品构思
- 优先级：待评估
- 目标：把竞品视频研究、结构化拆解和 Seedance 2.0 素材生成串成可重复工作流
- 本文只记录待办设计，不代表当前已经提供对应命令

## 背景

当前产品已经具备社交平台数据研究和浏览器会话桥接能力，也在扩展
TikTok Symphony Creative Studio 的 Seedance 2.0 视频生成能力。

单独提供“搜索数据”或“生成视频”仍然需要用户自己完成大量中间工作：

1. 从热门广告中判断哪些素材值得参考。
2. 理解视频开头、镜头、节奏、卖点和转化结构。
3. 将拆解结果改写成新的创意方案。
4. 将创意方案转换成适合视频生成模型的提示词。
5. 跟踪生成任务、素材版本和测试结果。

Codex 当前使用的模型不一定始终具备原生视频理解能力。可以利用用户已经登录的
Google AI Studio 页面，把视频理解作为一个可调度的外部能力，再由 Codex 负责
工作流编排、结构校验和后续生成。

## 产品定位

目标不是增加一个“上传视频到 Google AI Studio”的页面自动化工具，而是形成：

> 从高表现素材发现，到视频理解、创意提炼、差异化改编和新素材生成的闭环。

各部分职责如下：

| 能力 | 职责 |
| --- | --- |
| TikTok、小红书、抖音数据 | 发现热门广告、博主、热词、标签和素材 |
| 本地媒体工具 | 获取时长、分辨率、关键帧、音轨、字幕和时间戳 |
| Google AI Studio | 理解镜头语义、Hook、卖点、节奏、情绪和广告结构 |
| Codex | 选择处理链路、组织上下文、校验输出、生成创意 Brief |
| Seedance 2.0 | 根据新分镜和提示词生成视频素材 |
| 本地素材记录 | 保存来源、分析结果、生成参数、任务状态和实验关系 |

## 目标工作流

```text
输入商品、市场或竞品素材
→ 搜索高表现广告和相关趋势
→ 选择需要研究的视频
→ 本地提取媒体基础信息
→ 上传 Google AI Studio 分析
→ 得到结构化分镜和创意公式
→ Codex 生成差异化创意 Brief
→ 转换成 Seedance 2.0 提示词
→ 创建一组视频生成任务
→ 轮询状态并归档结果
```

用户侧理想输入：

```text
研究美国市场最近 30 天的便携榨汁杯广告，
分析播放量最高的素材，提炼三个开头和两个卖点方向，
再生成六条 5 秒的 Seedance 2.0 测试视频。
```

用户不需要选择分析模型、整理时间轴或手工复制提示词。

## 视频分析输出

Google AI Studio 的输出必须采用固定结构，避免把自由文本直接交给后续生成链路。

建议的内部数据结构：

```json
{
  "source": {
    "platform": "tiktok",
    "video_id": "VIDEO_ID",
    "url": "SOURCE_URL",
    "duration_seconds": 18.4
  },
  "summary": "产品演示型短视频",
  "target_audience": ["通勤用户", "便携家电用户"],
  "hook": {
    "start": 0,
    "end": 2.2,
    "type": "痛点展示",
    "description": "使用传统榨汁机清洗困难的画面引出问题"
  },
  "shots": [
    {
      "index": 1,
      "start": 0,
      "end": 2.2,
      "shot_size": "近景",
      "camera_motion": "手持推进",
      "visual": "沾满果渣的传统榨汁机",
      "subtitle": "每天清洗真的太麻烦",
      "audio": "快节奏背景音乐",
      "purpose": "制造痛点"
    }
  ],
  "selling_points": ["便携", "易清洗", "快速出汁"],
  "visual_style": ["自然光", "UGC", "高对比"],
  "pacing": {
    "average_shot_seconds": 1.8,
    "pattern": "快-快-慢-快"
  },
  "cta": "点击查看商品",
  "reusable_formula": "痛点画面→产品出现→使用过程→结果展示→CTA",
  "confidence": {
    "timeline": 0.9,
    "transcript": 0.8,
    "creative_intent": 0.75
  }
}
```

校验要求：

- 每个镜头必须包含起止时间，时间范围不得重叠或超出视频总时长。
- `shots` 按时间升序排列。
- 屏幕字幕、语音转录和模型推断需要区分来源。
- 模型不确定的字段使用空值和置信度表达，不编造具体数据。
- 输出解析失败时保留原始结果，并进入有限次数的格式修复流程。

## 混合分析策略

Google AI Studio 负责语义理解，本地工具负责确定性信息。

### 本地预处理

- 使用 `ffprobe` 获取时长、分辨率、帧率、编码和音轨信息。
- 使用场景检测获得镜头边界和关键帧。
- 提取音轨并生成语音转录。
- 对关键帧执行屏幕文字识别。
- 为每张关键帧保留准确时间戳。

### Google AI Studio 分析

- 判断视频类型和目标受众。
- 识别前几秒 Hook 的表现方式。
- 解释每个镜头在广告结构中的作用。
- 提取卖点、情绪、视觉风格和节奏。
- 总结可复用的创意公式。
- 指出适合保留、替换和测试的变量。

### Codex 后处理

- 合并媒体元数据、时间轴、转录和语义分析。
- 校验结构完整性和时间范围。
- 将竞品表达抽象为创意方法，不直接复制原素材。
- 生成多个差异化 Brief 和 Seedance 提示词。
- 建立来源素材、分析结果和生成任务之间的关联。

## 能力路由

视频理解应设计为可替换的能力提供方，而不是写死到某个模型。

```text
当前模型具备可靠的视频理解能力
→ 直接分析

当前模型的视频能力受限，Google AI Studio 页面可用
→ 通过已登录页面完成分析

页面上传或分析暂时不可用
→ 本地抽帧、转录和图文联合分析
```

路由前需要检查：

- Google AI Studio 登录状态。
- 页面是否允许当前视频格式、大小和时长。
- 当前会话是否已有未完成任务。
- 分析输出是否满足结构校验。
- 原始视频是否允许进入所选处理链路。

## 面向小白的体验

用户入口应该是任务，而不是底层模型和接口。

建议支持的自然语言任务：

- 帮我拆解这条竞品视频。
- 找出这条视频前 3 秒为什么有效。
- 把这条广告改成三个不同开头。
- 根据这个商品生成一组测试分镜。
- 用 Seedance 生成这些创意并持续查看进度。

系统内部再选择平台、分析提供方、抽帧策略、提示词和生成参数。

分析结果需要同时提供两种视图：

1. 小白视图：结论、可复用公式、建议测试方向。
2. 专业视图：时间轴、镜头参数、原始证据和置信度。

## MVP 范围

第一阶段只打通单视频闭环：

1. 接收一个本地视频或已下载的平台视频。
2. 提取媒体基础信息和关键帧。
3. 上传到已登录的 Google AI Studio 页面。
4. 使用固定分析模板获取结构化 JSON。
5. 校验并保存分析结果。
6. 生成一个创意 Brief 和三组 Seedance 提示词。
7. 由用户确认后创建视频生成任务。

第一阶段暂不追求：

- 大规模并行上传。
- 自动评价新生成视频的广告效果。
- 自动发布或创建广告计划。
- 跨账号共享素材和分析结果。

## 后续阶段

### 第二阶段：批量研究

- 从 Top Ads 搜索结果选择一组高表现视频。
- 自动聚类 Hook、卖点、场景和视觉风格。
- 输出行业创意模式和反复出现的素材公式。
- 标记同质化严重和仍有测试空间的方向。

### 第三阶段：创意实验矩阵

- 将 Hook、受众、卖点、视觉风格和 CTA 作为独立变量。
- 自动产生有限规模的组合，而不是无控制地生成全部排列。
- 记录每条生成素材对应的变量和来源证据。
- 为后续人工评价或广告表现回流预留关联字段。

### 第四阶段：生成结果复检

- 对 Seedance 输出再次执行视频分析。
- 对比目标分镜和实际生成结果。
- 检查产品一致性、镜头完整性、字幕、节奏和明显异常。
- 根据差异自动生成下一轮修改建议。

## 工程边界

- 登录态、Cookie、页面令牌和上传签名继续保留在 Chrome。
- Python 只通过本机回环桥发起固定操作和接收清洗后的结构化结果。
- Google AI Studio 与 TikTok Creative Studio 属于不同平台族，可并行执行。
- 同一平台族的页面请求保持串行，上传和分析任务采用有界队列。
- 原始视频和分析证据保存在本机，不增加服务端数据库。
- 页面自动化只暴露固定动作，不提供任意 URL 或任意脚本执行入口。
- 正式命令以各平台 `cli.py` 的 `argparse` 声明为准，本文不维护命令接口。

## 主要风险

### 页面变化

Google AI Studio 的控件、上传流程和输出区域可能变化。需要使用稳定语义定位，
并为页面状态、上传状态和分析状态建立明确错误分类。

### 上传限制

视频大小、格式、时长和并发可能受账号或页面策略限制。需要在上传前预检，并为
超限视频提供压缩、裁剪或抽帧分析路径。

### 输出稳定性

模型可能输出说明文字、缺失字段或不准确时间戳。必须使用结构校验、本地时间轴
校正和有限次数的格式修复。

### 任务耗时

视频上传、分析和生成都可能持续数分钟。流程应拆成创建任务、查询任务和取得结果，
避免一次本机 RPC 长时间占用。

### 素材边界

分析和改编需要保留来源记录。产品输出应聚焦可复用的创意结构和差异化表达，
避免把竞品素材直接当作生成模板复制。

## 验收条件

MVP 进入可用状态前至少满足：

- 在真实登录态下完成一个视频上传和分析。
- 获得非空的结构化分镜结果。
- 本地时间轴校验通过。
- 页面登录、上传失败、格式超限、分析超时和输出异常具有明确错误分类。
- 同一视频重复执行可以得到结构一致的结果。
- 分析结果可以生成至少三组差异化 Seedance 提示词。
- 提示词能够创建真实 Seedance 2.0 任务并取得任务状态。
- 登录凭据和页面令牌不进入 Python 输出、日志或文档。
- 相关 Python、扩展合同和文档生成测试通过。

## 待调研事项

- Google AI Studio 当前可用模型及视频大小、格式、时长上限。
- 页面上传后的素材标识、分析请求和任务状态协议。
- 多轮对话与单次结构化分析哪种输出更稳定。
- Google AI Studio 对时间戳、字幕和多音轨视频的实际识别精度。
- 本地场景检测与模型分镜边界的合并规则。
- Seedance 2.0 对分镜提示词、镜头运动和时长描述的最佳输入格式。
- 一条原始素材生成多少个变体最适合小白使用。
- 分析和生成额度如何在执行前向用户展示。
